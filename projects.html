Paste the address of the Git repository that holds the prototype. For a private repository use the SSH address — it starts with git@.

How to find the address on GitHub
  1. Open the repository page on GitHub.
  2. Click the green Code button.
  3. Pick the SSH tab for a private repository, or HTTPS for a public one.
  4. Click the copy icon next to the address and paste it above.
